## Brand & Style
This design system defines an ultra-modern, mission-critical law enforcement intelligence and tactical case analytics platform. The visual tone balances cyber-defense operational precision with refined high-density ergonomics—evoking authority, vigilance, uncompromising data clarity, and tactical readiness. 

The aesthetic is anchored in **Cyber-Defense Dark Minimalism with Tactical Glassmorphism**:
- Deep obsidian and midnight slate canvas layers that reduce eye strain during extended analytical watches.
- Electrified cyan and tactical teal accents indicating operational active states, live link nodes, and high-priority correlations.
- Structural micro-grids, clean boundary layers, and luminous indicators derived from modern aerospace telemetry and defense situational awareness displays.
- Visual clutter is strictly eliminated; hierarchy is reinforced via luminosity grading, monospaced forensic identifiers, and clean optical containers.

## Colors
The color architecture relies on high-contrast spectral accents over deep light-absorbing backgrounds:
- **Primary (`#00E5FF`)**: Pure forensic electric cyan. Used for targeted entities, primary action vectors, active node graphs, and critical highlights.
- **Secondary (`#38BDF8`)**: Softened orbital blue. Serves supporting navigational actions, system telemetry, and contextual focus points.
- **Tertiary (`#10B981`)**: Verified green/operational emerald. Applied strictly to confirmed evidence, active intercept states, secure connections, and verified intel matches.
- **Neutral (`#07090E`)**: Void black-navy canvas. Grounds the operational environment with zero back-bleed, accompanied by tiered slate layers (`#0D1117`, `#161B22`) for card and inspector surfaces.
- **Named Status Tokens**: Amber (`#F59E0B`) identifies unverified leads and threat-level warnings; Crimson (`#EF4444`) is reserved exclusively for immediate hostile triggers, warrants, or critical intercept failures.

## Typography
The system enforces a dual-type architecture optimized for high data density and instantaneous analytical comprehension:
- **Headlines & Structural Titles (`Geist`)**: Delivers tight, geometric modernism for executive dashboards, case overviews, and operational dossiers.
- **Narrative & UI Text (`Inter`)**: Neutral, highly legible humanist sans chosen for incident reports, transcript logs, and operator collaboration notes.
- **Forensic & Data Telemetry (`JetBrains Mono`)**: Mandatory for case reference IDs, cryptographic hashes, timestamps (UTC), coordinate values, and tabular analytics matrices. Uppercase transform with tracking applied to micro labels.

## Layout & Spacing
A 12-column adaptive fluid grid engineered for analytical workstation multi-monitor configurations, situational war-room displays, and mobile responder tablets:
- **Desktop (>= 1280px)**: 12-column grid with `1.5rem` gutters and `2rem` margins. Utilizes a split panel layout: collapsible primary index (240px fixed), centralized investigation canvas/graph (flexible), and contextual detail inspector (360px docked drawer).
- **Tablet (768px - 1279px)**: 8-column layout with `1rem` gutters. The inspector pane transitions into an overlay drawer.
- **Mobile (< 768px)**: 4-column layout with `1rem` margins and condensed `0.5rem` gutters. Case entities stack vertically with segmented view-switching.
- **Spatial Rhythm**: Dense, predictable multiples of 4px. Interfaces favor compact component padding (`space-xs` to `space-md`) to maximize viewport situational intelligence without clutter.

## Elevation & Depth
Depth is established through dark luminous layering and controlled tactical translucency rather than diffuse generic drop shadows:
- **Base Canvas**: Solid `#07090E` with optional fine 1px dot-matrix grid overlay (`rgba(33, 38, 45, 0.4)` on 24px intervals) for spatial positioning awareness.
- **Surface Layer 1 (Panels & Groupings)**: `#0D1117` coupled with a crisp 1px hairline border of `#21262D`.
- **Surface Layer 2 (Cards & Graph Nodes)**: `#161B22` with a 1px border of `#30363D`. Hovering or selecting an element triggers a subtle cyan ambient bloom (`box-shadow: 0 0 16px rgba(0, 229, 255, 0.15)`).
- **Modal & HUD Overlays**: Translucent `#0D1117` at 85% opacity with `backdrop-filter: blur(12px)` and an inner hairline highlight (`inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`).

## Shapes
To sustain an authoritative, precision-engineered cybernetic aesthetic, corners maintain a soft, controlled geometry (`roundedness: 1`):
- Base containers, data tables, inputs, and operational cards employ `0.25rem` (4px) radii.
- Modals, flyout panels, and floating graph inspectors use `rounded-lg` (`0.5rem` / 8px).
- Full pill radii are strictly restricted to live pulse badges, tag indicators, and telemetry status pips.

## Components

### Buttons
- **Primary Tactical**: `#00E5FF` background with `#07090E` bold text. Subtle neon border flare on focus (`box-shadow: 0 0 12px rgba(0, 229, 255, 0.35)`). Active state scales to `0.98`.
- **Secondary Ghost**: Transparent surface, `#21262D` border, `#F1F5F9` text. On hover, background shifts to `rgba(56, 189, 248, 0.08)` and border brightens to `#38BDF8`.
- **Destructive/Warrant**: Crimson tint (`rgba(239, 68, 68, 0.1)`) with `#EF4444` border and text. On engagement, fills solid `#EF4444` with `#07090E` text.

### Chips & Badges
- Constructed with `JetBrains Mono` at `label-sm`.
- Contained within `0.25rem` radius or pill shapes featuring a 10% opacity colored background and a 40% matching border (e.g., Target Suspect: Crimson tint; Intercept Active: Cyan tint; Surveillance Clear: Emerald tint).
- Equipped with a 6px status LED pip preceding the text string.

### Input Fields & Forensic Selectors
- Background `#0D1117`, border 1px `#21262D`, placeholder `#64748B`.
- Focused state transforms the border to `#00E5FF` with a microscopic glow (`0 0 0 1px #00E5FF`).
- Monospace variant available for hash entry, IMEI, license plate, and IP filter fields.

### Cards & Dossiers
- Background `#0D1117` encased in 1px `#21262D`.
- Card headers feature an integrated metadata stripe: case ID in `code-sm` aligned left, threat indicator pip aligned right.
- Interior dividers utilize 1px dashed `#21262D` to cleanly separate suspect links from timeline evidence.

### Lists & Intelligence Feeds
- Compact alternating rows or seamless hairline borders (`#21262D`).
- Hover row state renders background `#161B22` with a 2px left border accent in `#00E5FF`.
- Real-time entries animate with a swift, subtle fade-in and cyan edge flash.

### Tactical Additions
- **Node Link Graph**: Visual connectors use high-contrast anti-aliased SVG lines with animated directional pulses (`#00E5FF` for active transmission).
- **Telemetry HUD Strip**: Top-anchored bar displaying global coordinates, active case load, classification level (e.g., TOP SECRET // LAW ENFORCEMENT SENSITIVE), and UTC master clock.
